# Built with [fotbo.ai](https://fotbo.ai)

This web app was generated by **fotbo.ai** — an AI agent that turns a prompt into a
production-ready website.

## Tech stack
- Vite + React + React Router
- Tailwind CSS v4
- Express (serves the built front-end and the /api layer on one port)

## Project structure
    src/app/          bootstrap: App, router, global providers
    src/features/     business features — one folder per feature, pages included
    src/components/   reusable presentational UI (no business logic)
    src/services/     infrastructure: API clients
    src/hooks/        shared hooks
    src/lib/          pure utilities
    src/store/        global state (contexts)
    src/app/blocks.jsx   routes contributed by attached blocks (e.g. the admin panel)
    server.js         Express: generic REST over db.json + serves dist/
